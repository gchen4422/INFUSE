Running infuse_core()

This example fine-maps the same DBP locus on chromosome 20 (58,658,279–59,673,534) used in Data Preparation, retaining both common and ancestry-unique variants. Install the current package version following Installation. Use the post-QC observed-input file created in Data Preparation; the controlled-access GWAS and LD inputs are not bundled with the website.

1. Prepare Inputs

library(INFUSE)
observed <- readRDS(Sys.getenv(
  "INFUSE_AOU_EXAMPLE_INPUT", "data/DBP_chr20_observed.rds"
))

prep <- prepare_infuse_union(
  summary_stat_list = observed$summary_stat_list,
  R_mat_list = observed$R_mat_list,
  annot = observed$annot,
  annot_ids = rownames(observed$annot),
  union_ids = observed$union_ids,
  allele_ref = observed$allele_ref,
  ld_allele_coding = "ancestry_effect",
  require_complete_ld_dimnames = TRUE
)

Input Format

Input Description
prep$R_mat_list Named list of ancestry-specific LD matrices, aligned to the 2,890 union variants
prep$summary_stat_list Named list of summary-statistic data frames with SNP, Beta, Se, Z, and N, in the same SNP order as the LD matrices
prep$annot 2,890 × 186 annotation matrix, aligned to the union SNPs
prep$variant_available Logical SNP-by-ancestry matrix specifying where each SNP is available

Summary-Statistic Columns

Column names are case-sensitive: use Beta and Se, not BETA and SE. Both infuse_core() and prepare_infuse_union() require the five fitting columns below; Beta, Se, Z, and N must be numeric and finite.

Column Required Description
SNP Yes Unique variant identifier matching the LD matrix SNP names
Beta Yes Effect-size estimate for the effect allele
Se Yes Standard error of Beta; must be positive
Z Yes Z-score, consistent with Beta / Se
N Yes Per-variant GWAS sample size; must be greater than 2
A1, A2 For allele harmonization Effect and non-effect alleles; required in this example because allele_ref is supplied to prepare_infuse_union()
CHR, POS No Chromosome and position, used for regional selection or plotting
PVAL No GWAS P-value, used for filtering or plotting
MAF, INFO No Allele-frequency and imputation-quality metadata, used for QC

Data Preparation renames the AoU ALT/REF columns to A1/A2. These two allele columns are not required by infuse_core() itself. For inputs already harmonized externally, prepare_infuse_union() can skip allele harmonization only when both columns are omitted from every ancestry and allele_ref = NULL.

Each ancestry now has 2,890 aligned input rows, but only the entries marked available contribute to its likelihood. For analyses in which every SNP is available in every ancestry, the original common-variant inputs remain supported with variant_available = NULL.

Ancestry Configuration Weights

ancestry_weight specifies prior weights on ancestry configurations. For common variants, the default two-ancestry weights are c(3, 3, 1)/7: the two ancestry-specific configurations followed by the shared configuration. Configuration names identify the corresponding ancestries.

For ancestry-unique variants, the configuration for the ancestry in which the variant is available has prior probability 1. EUR-only variants are restricted to the EUR configuration, and AFR-only variants to AFR.

2. Fit the Model

result <- infuse_core(
  R_mat_list = prep$R_mat_list,
  summary_stat_list = prep$summary_stat_list,
  L = 10,
  annot = prep$annot,
  annot_method = "mlk",
  variant_available = prep$variant_available,
  verbose = FALSE
)

verbose = FALSE suppresses routine progress output. It does not change the fitted model.

Parameters Used in This Example

3. Interpret Results

Either-Ancestry PIPs

The posterior inclusion probability (PIP) describes the posterior support that a variant is causal. result$pip reports support for an effect in at least one ancestry, for both common and ancestry-unique variants. Values range from 0 to 1, with higher PIPs indicating stronger support. The table below ranks variants by these PIPs.

Credible Sets

A 95% credible set (CS) contains variants whose cumulative posterior probability for a single causal signal reaches at least 0.95. Smaller sets indicate finer resolution. INFUSE retains sets that meet the selected LD-purity criterion.

result$cs$cs contains SNP indices into the prepared inputs. purity summarizes within-set absolute LD correlations, and coverage is the cumulative posterior probability captured by each set. The second command below converts SNP indices to variant IDs.

4. Tuning Parameters

L (number of effects)

Setting L too low may miss multiple causal signals at a locus; setting it too high increases computation. For typical GWAS loci, L = 10 is a safe default. If you expect a region to harbor only 1–2 signals, L = 5 is sufficient.

Annotation method

  • mlk: Recommended. When the annotation matrix contains at least 15 features, this method applies sparse PCA to obtain a lower-dimensional representation before estimating annotation weights. Otherwise, it estimates the weights by directly maximizing the joint likelihood without sparse PCA.
  • glmnet: Not recommended; included mainly for benchmarking purposes.
