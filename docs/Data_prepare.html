Data Preparation for INFUSE

Note: This guideline details the data preprocessing steps required to standardize GWAS summary statistics and reference LD panels for INFUSE

Overview of the Pipeline

We provide a streamlined pipeline to prepare input data for INFUSE, using All of Us (AoU) GWAS summary statistics from European Americans and African Americans as examples. The process involves several key stages:

  1. GWAS Harmonization: QC and filtering.
  2. LD Reference Construction: Extracting matched genotype data from 1000 Genomes (1KG, GRCh38).
  3. LD Mismatch Detection: Pruning inconsistent variants separately within each ancestry.
  4. Variant Harmonization: Harmonizing alleles and aligning ancestry-specific inputs for INFUSE.

All helper functions used below are defined in code/data_prep_utils.R and loaded in the setup chunk. The input paths identify the AoU/1KG resources; substitute your own locations. New files are written under aou_union_example/.

library(INFUSE)
source(here::here("code/data_prep_utils.R"))

1. GWAS Harmonization

Goal: Standardize summary statistics from different ancestries (e.g., EUR and AFR) to a common reference panel (e.g. 1000 Genome).

Apply QC separately in each ancestry and retain variants available in either EUR or AFR. In this analysis, common variants are variants available in both ancestries, whereas ancestry-unique variants are available in only one ancestry. Unlike MESuSiE, INFUSE does not require restricting the analysis to common variants.

We recommend removing strand-ambiguous SNPs, multi-allelic variants, variants within the MHC region, and variants with minor allele frequency (MAF) < 0.01 via GWAS_QC. Match each ancestry against its own 1KG reference panel.

2. Align GWAS Summary Statistics with LD Reference Panel

Goal: Construct ancestry-matched LD reference genotypes from 1KG that match each ancestry’s own GWAS variant list and use the same REF/ALT orientation, avoiding sign errors in Z-scores.

We use plink2 to subset 1KG genotypes (--extract), enforce REF allele orientation (--ref-allele), and output a new .bed/.bim/.fam file (--make-bed).

trait <- "DBP"
kg_dir <- file.path("aou_union_example", "ld_reference")
dir.create(kg_dir, recursive = TRUE, showWarnings = FALSE)

align_ld_ref("AFR", trait, kg_base = kg_base, ss_dir = out_dir, out_base = kg_dir)

4. LD Mismatch Detection

A common issue in fine-mapping is mismatch between summary statistics and the LD reference panel. We use kriging_rss from susieR to iteratively identify and remove SNPs whose Z-scores are inconsistent with the LD structure. filter_ld_mismatch() handles the full loop automatically.

trait <- "DBP"

geno_dir_eur <- file.path("aou_union_example", paste0("risk_loci_ld_eur_", trait))
geno_dir_afr <- file.path("aou_union_example", paste0("risk_loci_ld_afr_", trait))

afr_sumstats <- fread(file.path(out_dir, paste0(trait, "_AFR_GRCh38_combined_format_noMHC_to_finemap.csv")))

5. Variant Harmonization

Combine the post-QC summary statistics and LD from the preceding steps, retaining both common and ancestry-unique variants.

Match functional annotations to variants by rsID and allele pair, excluding missing or ambiguous matches. DBP_chr20_annotations.rds below is the resulting numeric annotation matrix, with SNP IDs as row names.

to_infuse_summary <- function(ss) {
  ss <- as.data.frame(ss)
  rename <- c(BETA = "Beta", SE = "Se", ALT = "A1", REF = "A2")
  for (old in names(rename)) {
    if (old %in% names(ss)) names(ss)[names(ss) == old] <- rename[[old]]
  }
  if (!"Z" %in% names(ss)) ss$Z <- ss$Beta / ss$Se
  ss
}
summary_stat_list <- list(
  EUR = to_infuse_summary(eur_res$sumstats),
  AFR = to_infuse_summary(afr_res$sumstats)
)
R_mat_list <- list(EUR = eur_res$cov, AFR = afr_res$cov)
annot <- readRDS("data/DBP_chr20_annotations.rds")
stopifnot(!is.null(rownames(annot)))

ref <- do.call(rbind, summary_stat_list)
ref <- ref[!duplicated(ref$SNP), ]
ref <- ref[order(ref$CHR, ref$POS, ref$SNP), ]
union_ids <- ref$SNP[ref$SNP %in% rownames(annot)]
allele_ref <- ref[match(union_ids, ref$SNP), c("SNP", "A1", "A2")]
for (anc in names(summary_stat_list)) {
  ss <- summary_stat_list[[anc]]
  ss <- ss[ss$SNP %in% union_ids, ]
  summary_stat_list[[anc]] <- ss
  R_mat_list[[anc]] <- R_mat_list[[anc]][ss$SNP, ss$SNP, drop = FALSE]
}
observed <- list(
  summary_stat_list = summary_stat_list,
  R_mat_list = R_mat_list,
  annot = annot[union_ids, , drop = FALSE],
  union_ids = union_ids,
  allele_ref = allele_ref
)
dir.create("data", showWarnings = FALSE)
saveRDS(observed, "data/DBP_chr20_observed.rds")
prep <- prepare_infuse_union(
  summary_stat_list = observed$summary_stat_list,

After annotation matching, the example contains 2,890 variants: 1,867 common variants and 1,023 ancestry-unique variants (241 EUR-only and 782 AFR-only). EUR and AFR contribute 2,108 and 2,649 variants, respectively.

The function prepare_infuse_union() aligns SNPs and harmonizes alleles across the ancestry-specific inputs, retaining both common and ancestry-unique variants. Set ld_allele_coding = "ancestry_effect" when LD follows each ancestry’s effect-allele coding, as in this example, or "reference" when LD already follows allele_ref. The returned prep$variant_available records the availability of common and ancestry-unique variants in each ancestry.
