# data/

This directory stores input data files used by the INFUSE analysis pages.

## Contents

- `example_ldl_locus.RData` — Pre-processed LDL locus data (EUR + AFR summary statistics, LD matrices, annotation matrix) used in the Real Data Example page. *(To be released with the manuscript.)*

## Data Sources

- **GWAS summary statistics:** All of Us Research Program (AoU), v8 release
- **LD reference panels:** 1000 Genomes Project (1KG), GRCh38 build
- **Functional annotations:** ENCODE, Roadmap Epigenomics, GTEx v8
